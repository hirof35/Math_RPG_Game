算数クエスト - 伝説の計算導師 (Math Quest)算数クエストは、計算の力でモンスターを倒し、世界に平和を取り戻す教育系RPG（ゲーミフィケーション・アプリ）です。
「勉強を遊びに」をコンセプトに、素早い計算判断力とコンボの爽快感を体験できます。

⚔️ ゲームシステム計算バトル: 加算・減算のクイズに正解してモンスターに攻撃。レベルが上がるにつれて問題の数値範囲が広がります。
コンボ & パワーアップ: 3連続正解で「パワーアップ状態」に突入。攻撃力が2倍になり、強敵を一気に撃破できます。
刻々と変化するステージ:森 (Lv 1~): 冒険の始まり。洞窟 (Lv 5~): 視認性が変わる未知の領域。城 (Lv 10~): 強敵が待ち構える決戦の地。マグマ (Lv 15~): 最終決戦、灼熱の地獄。強大なボス: 5レベルごとに強力なHPと速いタイマーを持つボスが登場。セーブ機能: LocalStorage を活用し、過去の最高到達レベルを自動的に記録。
🕹 操作方法操作アクション数値入力計算の答えを入力攻撃ボタン / Enterモンスターへ攻撃を実行タイムアップ回答が遅れると反撃を受けるので注意！
🛠 技術的ポイント演出のこだわりCSSアニメーション: 攻撃を受けた際の画面揺れ（Shake効果）や、背景の滑らかな遷移を実装。
動的タイマー: レベルが上がるごとに制限時間が短縮されるロジックを採用。JavaScriptlet limit = Math.max(30, 100 - (level * 4)); // レベルアップでシビアに
スプライト演出: 絵文字を活用しつつ、ボス戦ではCSSの transform: scale(2) と filter: drop-shadow で威圧感を演出。
